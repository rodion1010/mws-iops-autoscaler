# Architecture decision requests

This directory is normally empty. `docs/design.md` is the complete canonical description of the
accepted architecture.

An agent may add a short `Proposed` ADR only when the existing contracts do not determine a material
choice and the Product Lead must decide between credible alternatives. The ADR is a communication
artifact: it states the question, constraints, options, recommendation and exact decision needed.
It must not declare accepted architecture or duplicate implementation detail.

After the decision, update the appropriate canonical documents and delete the ADR in the same change.
The full policy is in [`CLAUDE.md`](../../CLAUDE.md).

ADR-001 through ADR-019 were consolidated into [`docs/design.md`](../design.md) on 2026-08-30 and
removed from the active tree. Their historical text remains in the
[pre-consolidation snapshot](https://github.com/rodion1010/mws-iops-autoscaler/tree/5b89e8efc4ffe480cb6f44230433eaef700ec861/docs/adr).
